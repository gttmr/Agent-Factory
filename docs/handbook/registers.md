## 해석 원칙

Register ID는 Handbook 내부의 안정 식별자다. 실제 source field나 파일 이름을 바꾸지 않으며, Target Contract의 새 schema가 구현되었다는 선언도 아니다. legacy `module_category`, legacy `adapter`, legacy `remote_a2a`, legacy `processFlow`와 같은 현재 직렬화는 [Taxonomy](../workbench/taxonomy.md)와 [Graph IR](../workbench/graph-ir.md)의 Current Implementation 대응을 함께 읽는다.
