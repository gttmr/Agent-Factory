A fresh `git worktree add` of Agent Factory has **no `node_modules`** — `npm run build`/`test:analyzer` fail with `tsc: not found` / `ERR_MODULE_NOT_FOUND` until deps exist. Deps live per-package (no root package.json): `packages/web/node_modules` AND `packages/mock-lab/node_modules` (web's `tsc --noEmit` pulls mock-lab sources). Fastest fix without `npm install`: symlink both from the main checkout, e.g. `ln -s /home/ilmaswsl/work/Agent-Factory/packages/web/node_modules node_modules` (and same for mock-lab).

**Gotcha:** `.gitignore` has `node_modules/` (trailing slash → directories only), so a `node_modules` **symlink** is NOT ignored and shows as untracked. Never `git add -A` in such a worktree — it would stage the symlinks. Stage explicit paths instead, and remove the symlinks when done. Confirm with `git check-ignore packages/web/node_modules` (prints nothing = not ignored).
